Privacy Policy

Last updated: November 19, 2026

BeatBot is a personal tool operated by its owner for uploading videos to the owner's own YouTube channels.

Data accessed

BeatBot uses Google OAuth to access the YouTube Data API with the scopes youtube and youtube.upload, solely to upload videos and read basic channel information (channel ID and title) of the authorizing account.

Storage

OAuth tokens are stored only on the owner's local computer. No data is sent to any third party or any server other than Google's APIs.

Sharing

No user data is sold, shared, or transferred to anyone.

Google API Services

BeatBot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
